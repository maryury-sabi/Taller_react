Descripcion de la aplicacion movil :
cuenta  con tres pantallas con navegacios tipo stack diseñada en React native y EXPO,conectada a Cloud Firestore que permite listar contactos ,ver el deatalle de uno y registrar uno nuevo .

pasos para ejecutar el proyecto
 paso 1:Instalar dependecias en una termnial con este comando npm install

paso2:crear un proyecto en la [consola de Firebase](https://console.firebase.google.com/) para habilitar Cloud Firestore y crear la coleccion 'contactos'que es la que nos pide en el taller

paso 3: instalar navegacion y firebase en la terminal con este comando 
expo install react-native-gesture-handler react-native-reanimated reactnative-screens react-native-safe-area-context @react-nativecommunity/masked-view
 
 paso4: iniciar el proeycto con el coamndo npx expo start -c
